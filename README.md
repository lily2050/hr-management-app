# 📱 تطبيق إدارة الإجازات والأذونات اليومية

## Professional HR Management Application

تطبيق Android احترافي متخصص في إدارة ومتابعة **الإجازات والأذونات والغياب والمأموريات** في المؤسسات والشركات والإدارات.

---

## ✨ المميزات الرئيسية

### 🔐 نظام الصلاحيات
- **المدير (Administrator)**: إدارة كاملة للنظام
- **الموارد البشرية (HR)**: إدارة البيانات والسجلات
- **المشرف (Supervisor)**: مراجعة واعتماد الطلبات
- **الموظف (Employee)**: تقديم الطلبات وعرض السجلات

### 📊 لوحة التحكم المتقدمة
- إحصائيات شاملة للحضور والغياب
- رسوم بيانية حديثة وتفاعلية
- عرض الطلبات المعلقة والمعتمدة

### 👥 إدارة الموظفين
- بيانات موظف شاملة
- ملفات شخصية احترافية
- البحث والفلترة والترتيب

### 🏖️ نظام الإجازات المتكامل
- أنواع إجازات قابلة للتخصيص
- حساب تلقائي لعدد الأيام
- تتبع الأرصدة المتبقية

### ⏰ نظام الأذونات اليومية
- تسجيل سريع للأذونات
- حساب تلقائي لمدة الإذن
- تحديد حد أقصى للأذونات

### 📈 التقارير الشاملة
- تقارير يومية وشهرية
- تقارير مخصصة حسب التاريخ
- تصدير إلى PDF و Excel

### 📱 واجهة عربية RTL
- دعم كامل للغة العربية
- تصميم حديث وسهل الاستخدام
- متجاوب على جميع الشاشات

---

## 🛠️ التقنية المستخدمة

### Frontend
- **React Native** مع **Expo**
- **Redux** لإدارة الحالة
- **React Native Paper** لتصميم Material
- **Chart.js** للرسوم البيانية
- **Axios** للطلبات HTTP

### Backend
- **Node.js** و **Express.js**
- **MongoDB** قاعدة البيانات
- **JWT** للمصادقة
- **bcrypt** لتشفير كلمات المرور
- **Joi** للتحقق من البيانات

## 🚀 البدء السريع

### المتطلبات
- Node.js v14+
- npm أو yarn
- Expo CLI

### تثبيت الـ Backend

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

### تثبيت الـ Frontend

```bash
cd frontend
npm install
npm start
```

## 📝 بيانات الدخول التجريبية

### مدير النظام
- البريد الإلكتروني: `admin@company.com`
- كلمة المرور: `Admin@123`

### مدير الموارد البشرية
- البريد الإلكتروني: `hr@company.com`
- كلمة المرور: `HR@123`

### مشرف الإدارة
- البريد الإلكتروني: `supervisor@company.com`
- كلمة المرور: `Supervisor@123`

### موظف عادي
- البريد الإلكتروني: `employee@company.com`
- كلمة المرور: `Employee@123`
